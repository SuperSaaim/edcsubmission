VENTUREVERSE 2026 — EVENT LANDING PAGE

Files:
- index.html  : page content and sections
- style.css   : colors, layout, styling, and mobile responsiveness
- script.js   : tiny mobile navigation menu interaction

HOW TO RUN:
1. Keep all three files in the same folder.
2. Open index.html in your browser.
3. Edit the text in index.html to change event information.

BEGINNER NOTES:
- HTML gives the page its structure.
- CSS controls how the page looks and adapts to mobile screens.
- JavaScript only opens/closes the mobile navigation menu.
- The event and speaker details are fictional placeholders from the mock brief.
- The registration button opens an email draft to edc@example.com. Replace this with the real EDC registration link/email if provided.
